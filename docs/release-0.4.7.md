# 月明かり v0.4.7 预发布

修复旧版 Android System WebView 的登录请求兼容性。长会话内部滚动，输入区和发送按钮保留在屏幕内。手机使用分级聊天导航，平板有足够空间时使用双栏。

Windows 安装版、免安装版和 Android APK 默认连接同一套 HTTPS 聊天服务。打开应用后直接输入聊天账号和密码。同一账号的会话、消息和已读状态跨端同步。桌面端按 Alt 后可在「月明かり」菜单查看升级前的本地聊天资料。

Android 支持 Android 9 及以上，沿用旧发行版的包名和签名，可覆盖升级。Windows 提供 x64 安装版和免安装版，测试构建尚无 Authenticode 签名。 [安装与升级](android.md)

聊天服务和数据库独立运行，服务器按创建时间保留最近 30×24 小时的消息。网站内容由原有网站后端管理。 [部署、备份与回退](chat-retention.md)
