# 0.4.0 验收记录

日期：2026-11-19。显示名月明かり，英文标识Tsukiakari。框架Electron45.3.1、Node.js24.22.3、SQLite；普通用户与管理员权限由服务端核验。

## 本轮改动

- 更新窗口、主界面、通知、托盘、安装包、程序名和品牌资源。新程序Tsukiakari.exe，快捷方式月明かり。
- 聊天为中心的紧凑导航、按真实类型分类的会话列表、按需成员侧栏、明确的新建对象选择。
- 个人设置、网站管理、软件管理独立页面；人格和角色卡归入软件管理，保留输入、滚动和筛选。
- 新增软件管理统计、群名管理、好友关系、通知默认值和AI连接配置；保存的令牌不回显，桌面加密持久化。
- 公开构建改为干净生成的演示库，无内置管理员、登录会话和私人消息；首次运行自行设置管理员。
- 保留旧完整配置目录、内部身份及协议，用于账号、消息、媒体、缓存和升级链兼容。

## 发布与边界

安装包使用英文文件名，包含必要运行时、依赖和许可证。可运行包成功构建并完成验收后才提供下载。Windows构建目前没有代码签名。云端网站和聊天服务不会因GitHub上传自动部署。

真实旧版安装升级已通过：原账号、聊天与媒体完整；新EXE为Tsukiakari.exe，窗口/桌面/开始菜单为月明かり，卸载项为月明かり (Tsukiakari) 0.4.0，旧桌面快捷方式已移除。原配置目录原地复用，安装路径可能保留旧目录名称，这是兼容行为。新版人格页已实际写入云端AstrBot并回读一致，并用原大肥鱼人格完成流式对话。临时验收内容已清理。

另从Git索引导出独立干净目录，按冻结锁文件安装依赖并准备桌面后端，确认生产依赖在该目录内解析，生成库没有管理员；不依赖工作区旧交付物。安装包SHA-256随下载提供。完整数据备份保存在本机忽略目录；公开仓库不包含备份、数据库或私有配置。

原生自动化验证后台隐藏、恢复窗口和退出；未执行用户电脑的真实关机，也未更改系统勿扰设置。系统托盘实点与系统通知的最终展示还取决于桌面环境和Windows权限。

工作流采用官方 [checkout](https://github.com/actions/checkout)、[pnpm/setup](https://github.com/pnpm/setup) 与 [upload-artifact](https://github.com/actions/upload-artifact) 的受支持接口；首次推送后的CI结果与本机验收分别报告。
