# 月明かり安卓 0.1.0

- 安卓 SDK 35 构建，兼容范围从 API 28 开始。测试包 `wiki.shion.tsukiakari` 仅支持 HTTPS；独立 QA 包 `wiki.shion.tsukiakari.qa` 支持 ADB 转发的回环地址。
- 手机增加底部导航、全屏聊天和通讯录浮层。达到平板宽度后并列显示会话与聊天，群成员按需展开。沿用月色、淡樱和詩音、知遥素材。
- 沿用账号、历史分页、好友、邀请制群聊、附件、网站管理和软件管理 API。通知偏好与保存的草稿按账号保留在设备。切页、重连或重试时保留发送幂等键。
- 支持应用内提示、安卓通知、会话跳转和标记已读。后台连接由用户主动开启，正文预览默认关闭。
- 添加桌面动态快捷方式「先别道晚安…」与「暂别月光」。支持个人资料及目录导出，卸载由安卓系统确认。
- 服务器和数据结构沿用现有版本。应用初次启动需要可达的聊天服务；真实 AstrBot 人格仍由服务端配置。

安装、构建、测试方法及后台可达条件见[安卓指南](android.md)。
