# 月明かり安卓 0.1.0

- 安卓 SDK 35 构建，兼容范围从 API 28 开始。测试包 `wiki.shion.tsukiakari` 仅支持 HTTPS；独立 QA 包 `wiki.shion.tsukiakari.qa` 支持 ADB 转发的回环地址。
- 手机增加底部导航、全屏聊天和通讯录浮层。达到平板宽度后并列显示会话与聊天，群成员按需展开。沿用月色、淡樱和詩音、知遥素材。
- 沿用账号、历史分页、好友、邀请制群聊、附件、网站管理和软件管理 API。通知偏好与保存的草稿按账号保留在设备。切页、重连或重试时保留发送幂等键。
- 支持应用内提示、安卓通知、会话跳转和标记已读。后台连接由用户主动开启，正文预览默认关闭。
- 添加桌面动态快捷方式「先别道晚安…」与「暂别月光」。支持个人资料及目录导出，卸载由安卓系统确认。
- 服务器和数据结构沿用现有版本。应用初次启动需要可达的聊天服务；真实 AstrBot 人格仍由服务端配置。

安装、构建、测试方法及后台可达条件见[安卓指南](android.md)。

## 模拟器实测

在 Android 15 x86_64、WebView 124 上安装两种 APK。验证标准包拒绝明文服务地址、手机软键盘和系统返回、通讯录、模拟平板改宽与改密度、群成员面板、草稿保留，以及模拟 AstrBot 的流式回复。

在同一模拟器验证了通知权限授权、后台消息到达、默认隐藏正文、通知直达会话及另一客户端已读后清除通知。模拟系统结束进程后，重新启动可恢复登录、会话与草稿。系统字号设为 130% 并切回手机宽度时，会话草稿仍在，页面没有横向溢出。[Android 15 验收记录](https://github.com/Shion39-Miku/Shion-Tsukiakari/actions/runs/44881204294)

在 AOSP 启动器长按图标，实测显示「先别道晚安…」，点按打开彩蛋页，插画完整显示。系统卸载确认可取消，取消后可回到应用。[长按菜单实拍](images/android-shortcut.png) · [彩蛋页实拍](images/android-farewell.png)

使用 SwiftShader 渲染，对 50 条会话的列表分别采样 48 帧。两次验收的静止帧间隔 P95 为 16.8 毫秒，逐帧滚动 P95 为 50.1–66.7 毫秒，原生连接页启动约 0.9–1.5 秒，恢复会话后的应用 PSS 约 82–83 MiB。真机帧率、内存、耗电和不同厂商的锁屏表现需另测。
