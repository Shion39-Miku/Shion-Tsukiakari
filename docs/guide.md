# 月明かり使用教程

## 第一次相见

首次打开空白软件时创建自己的管理员账号。密码不提供默认值，也不会进入安装包。旧版升级直接使用原账号。普通账号由管理员在「软件管理 → 用户管理」创建，可停用或重置密码；这些操作在软件后端核验管理员会话。

## AI、好友与群聊

点击会话列表右上角 `+`。

- **AI 对话**：选择服务器允许的 AI。顶部显示 AI 标签和当前人格名称，每段私聊独立保存。
- **好友私聊**：在通讯录按稳定 ID、账号或名称搜索，发送申请，对方接受后发起私聊。重名用户以账号和稳定 ID 区分。
- **创建群聊**：填写群名并向好友发送邀请；勾选成员不会直接把人加入。目标在「申请与邀请」接受后才加入。

分类筛选来自真实会话类型，AI 与人混合的群始终留在「群聊」。群内每位 AI 都有明确标识。右上角成员按钮按需展开侧栏；当前成员可继续发出定向邀请。邀请七天有效，可撤销；邀请人离群或邀请失效后需要重新邀请。

顶部会话操作菜单可选择 AI、重命名、退出或移除对话，实际权限由服务端校验。管理员不自动获得未加入群或他人私聊的正文读取权。

## 聊天、媒体与草稿

Enter 发送，Shift+Enter 换行。发送、生成、失败与停止状态对应实际消息和请求；失败可明确重试。切换设置或管理页面时保留输入草稿、会话位置、分类和搜索。

附件选择只做本地预览，确认发送才上传。软件可浏览网站已有音乐、游戏、猫图等栏目，音乐使用同一个播放器，支持歌词和进度拖动。软件没有背景音乐，消息提示音可以单独关闭。

## 个人设置

功能栏的设置入口包含：

- **个人资料**：修改显示名称、头像和在线状态；改名不改变稳定 ID 或历史消息归属。
- **外观**：舒适或紧凑密度、减少动效；正文采用易读字体。
- **通知**：消息提示音、任务栏提醒、系统消息通知分别开关。
- **关闭窗口**：每次询问、后台运行、退出软件。
- **连接状态**：查看软件后端和 AI 的连接方式；管理员可前往服务配置。
- **记忆授权**：查看来源，补充、共享或撤销自己的记忆。群内形成的记忆默认只用于来源群。

在线状态由设置、真实连接和心跳共同维护。隐身对他人显示离线。系统勿扰或通知权限会影响提示音、闪烁和系统通知；恢复连接只合并未读，避免历史消息集中响铃。

首次关闭窗口默认询问。选择后台运行后，点击托盘重新打开；托盘菜单或 Ctrl+Q 明确退出并停止本地服务。系统关机事件仅保存必要状态，不阻止系统关机。

## 两套管理

### 网站管理

面向「詩音の月光庭院」：文字与角色图片、音乐和LRC、游戏分类与图片、猫图、提问、最近更新、访客日志、站点设置。沿用「还原修改 → 保存修改 → 同步修改」流程，保存是私有草稿，同步后才公开。软件管理员与网站管理员的会话分别校验。

### 软件管理

面向「月明かり」：用户、群名及成员统计、好友关系、服务设置和AI接入。群管理不提供未加入群的消息正文。个人通知设置与管理员的新用户默认值分别保存。

「服务与 AI 接入」填写已有受限连接器地址、聊天令牌与人格管理令牌。接口需 HTTPS 或本机 HTTP，令牌互相独立。留空令牌保留原值，界面不回显已保存密钥。桌面在主进程用 Windows 加密后保存，软件后端持有并调用。连接保存后在AI列表刷新，查看真实可用状态。

### AI 人格／角色卡

人格以 AstrBot 服务器为准。可查看、编辑、新建人格，导入 AstrBot JSON 和 Character Card v2/v3 的 JSON、PNG。名称、系统设定、开场内容、示例对话与角色图片按支持字段保存。成功写入并回读同一服务器版本后，才显示同步完成。

同时编辑产生版本冲突时，待提交内容保留；先读取最新版本，再合并并提交。离线时不会提示成功。服务器删除或停用人格后，关联AI显示正确状态，需要重新选择可用AI。

## 备份与迁移

完全退出后复制整个数据目录；运行中可用 `pnpm backup:desktop` 做一致性快照，不要仅复制活动 SQLite 主文件。安装版新目录为 `%APPDATA%/Tsukiakari`，免安装版为 EXE 旁的 `Tsukiakari-data`。旧目录存在时继续使用旧目录，保留账号、聊天和 Chromium 缓存。

Windows 加密凭据跨账号或机器可能无法解密，需重新填写。恢复和服务部署说明见 [architecture.md](architecture.md)。
