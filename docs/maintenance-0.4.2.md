# 月明かり 0.4.2 版本说明

2026-11-20。Windows 桌面仍使用 Electron 45.3.1、Node.js 24.22.3 和两套独立的 SQLite 后端。本轮沿用现有数据库结构和数据目录，聊天、账号、草稿及网站媒体无需迁移。

## 已修复的问题

| 复现 | 影响 | 现在的行为 |
| --- | --- | --- |
| 在会话列表反复切换「全部、AI、好友、群聊」 | 旧版移除筛选外的会话，再按选择重建；按钮实际宽度随文字变化 | 会话节点按 ID 复用，各分类保留滚动位置。按钮四等分，淡樱色高亮覆盖整格 |
| 打开通讯录后换标签，期间延迟请求或断开连接 | 标签和内容区重建，已有结果消失，慢响应可能抢回视图 | 同一窗口内的通讯录保留各标签的数据与滚动位置。失败时保留已有内容，可重试。搜索只采纳最后一次提交的结果 |
| 小窗口里打开通讯录，再改变缩放后按 Esc | 原启动按钮可能已移出窗口，焦点无处可回 | 浮窗独立滚动，左右方向键切换标签，退出后回到原启动按钮或可用的导航入口 |
| 双击窗口关闭按钮，或正在发送附件时退出 | 原生提示风格不一致，记住退出与未完成操作之间缺少统一流程 | 应用内一次只显示一个关闭提示。取消保留草稿与偏好，退出前提示需要保留的工作。明确退出时等待受管服务结束 |
| 在网站管理切换编辑栏目 | 多个表单先后挂载，各自刷新待处理数量 | 合并栏目内的草稿状态刷新，保留独立网站后端的保存与同步流程 |

聊天正文和输入框采用 16 个逻辑像素，普通界面文字以 15 个逻辑像素为基础，按钮和分段控件增加点击高度。会话内容和高亮随分类方向滑动约 210 ms，连续切换只保留最后一次过渡。通讯录的打开、关闭与切换沿用同一套动效。个人设置中的「减少动效」及系统偏好可关闭这些动画。

关闭提示支持「后台运行」「退出软件」「取消」。只有确认前两项才应用「记住我的选择」。可在个人设置恢复每次询问。后台运行保留原窗口的会话、托盘和消息连接。关于、启动错误、系统级资料入口的权限提示及备用模型保存确认也使用应用内弹窗。

## 复现与验收

```powershell
pnpm test
pnpm check:app
pnpm build
pnpm package:desktop
pnpm check:desktop
pnpm check:desktop:portable
```

桌面脚本使用两个隔离账号和本机模拟 AstrBot，覆盖登录失败重试、好友申请及群邀请、分类、长历史、断线重连、迟到请求、设置、两套后台、头像及附件。它在 800×580 原生窗口和 125% 缩放下验证通讯录尺寸、焦点与长消息。持续流式回复时也测试筛选及继续输入。

性能对比使用 0.4.1 与 0.4.2 的 Windows 打包版。两版分别载入 50 条演示会话，在同一台机器上连续切换 12 次并输入长草稿。输入耗时统计同步输入事件的中位数，工作集和累计 CPU 时间取自同一渲染进程。

| 指标 | 0.4.1 | 0.4.2 |
| --- | ---: | ---: |
| 切分类时移除的会话节点 | 177 | 0 |
| 同步输入处理的中位数 | 1.4 ms | 0.1 ms |
| 超过 34 ms 的帧间隔 | 0 / 87 | 0 / 93 |
| 渲染进程累计 CPU 时间 | 125 ms | 167 ms |
| 渲染进程工作集 | 230 MiB | 236 MiB |

本次采样的 CPU 时间和工作集有所增加。切换动画、输入和渲染测量受系统调度影响。66 条历史消息滚动的帧间隔 P95 为 5.7 ms。隐藏窗口收到 8 条消息时，消息区没有重建，8 条均保留未读。

42 项项目测试、11 组网站浏览器回归和生产构建通过。打包版从工作区外启动，验证了三种关闭操作、记住或恢复偏好、未完成附件警告、托盘相关回调、任务栏未读标记与真正退出。配置错误可从应用内弹窗退出，详细原因写入 `desktop.log`。本轮没有验证 Windows 物理通知区域点击及扬声器听感。

单文件免安装版在含空格和日文的路径通过启动、重复打开、音频分段读取、退出和重启。用 0.4.1 演示资料副本启动 0.4.2，确认原登录、聊天、未发送文字和媒体保留，两套数据库均通过完整性检查。

真实 AstrBot 4.29.1 通过角色卡写入和回读、群上下文隔离和权限回归。新版桌面还完成了人格同步回读和大肥鱼流式对话，临时验收人格已清理。
